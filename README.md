# PokerHub

A browser-based, play-money poker practice and learning site.

## Included
- Responsive dark-green UI
- Simplified heads-up Texas Hold'em against a computer opponent
- 12 playable educational lessons with XP and progress tracking
- Poker hand evaluator and 5–7 card analyzer
- Educational strategy coach
- Local profile, achievements and practice history

## Run
Open `index.html` in a browser, or publish it with GitHub Pages.

## Publish with GitHub Pages
1. Open the repository Settings → Pages.
2. Under **Build and deployment**, select **Deploy from a branch**.
3. Select **main** and **/(root)**, then save.
4. Once published, open `https://apmunn.github.io/Pokerhub/`.

**Note:** GitHub Pages may not be available for a private repository on a free GitHub plan. If necessary, make the repository public first (do not include secrets or personal data).

## Limitations
This is a local practice prototype, not a production multiplayer poker engine. It does not include real-time online games, server accounts, real ranked matchmaking, live tournaments or a connected AI model. Progress is stored in the browser's localStorage, not synchronized across devices. The game uses simplified betting rules and basic computer decisions; it has not been exhaustively tested. No real-money gambling or redeemable chips.
